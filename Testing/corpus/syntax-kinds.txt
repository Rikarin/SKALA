# Every SyntaxKind Roslyn 5.9.0 declares, with the layout the C# document builder gives it.
#
# ⚠ This is the build-time half of the R5 mitigation (docs/plan/16-risks-and-open-questions.md).
# A Roslyn bump that adds a kind makes SyntaxKindInventoryTests fail; the fix is to classify the
# new kind in NodeLayouts.Classify and add it here, in the same commit, with the fixture diff
# reviewed. Until then the builder emits the kind verbatim, which is safe and wrong.
#
